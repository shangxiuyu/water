# 外部生活与社区工具联动规矩（Water 配合指南）

> 当用户需要查询或操作即刻、闲鱼、叮咚、淘宝、京东等外部 App 时读我。

## 1. 事前先读硬约束
- 调用任何生活/电商/社区 Skill 或 MCP 前，先检查 Tree 中是否已有 `01-关于我/生活与消费偏好.md` 或 `01-关于我/设备与资产.md`，获取地址区域、饮食忌口、设备耗材型号与平台偏好。

## 2. 事后只记 1% 慢变量（99% NOOP）
- **严禁入树**：单笔订单明细、菜价波动、快递物流、推荐流、账单金额。
- **允许入树（原地更新）**：
  - 新确认的长期饮食忌口或常购习惯 → `01-关于我/生活与消费偏好.md`
  - 新购入/出掉的核心硬件或耗材型号 → `01-关于我/设备与资产.md`
  - 看完社区/播客后用户认可的独立判断（附链接，不搬全文摘要） → `02-我的思考/`
